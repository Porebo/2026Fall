HW03 — Week 3 Assignment

Define Data Quality Requirements and Remediation Plan

Do not use AI for this assignment. The instructors for IQ101 and IQ102 want to build an information product: a final grade report for both courses, from the student grades CSV file.

Original file: Define Data Quality Requirements and Remediation Plan.docx

Information Product

Report Requirements

The report should be in two parts, one for IQ101 and the other for IQ102. Each part should start with a title that indicates the course, followed by a tabular list of students in the course in alphabetical order by last name. The first row should be a header describing the values in each column.

The columns should contain, for each student:

  • ID
  • Last Name
  • First Name
  • Program (Major) Code
  • Course Average
  • Final Letter Grade

The Course Average value is calculated by 0.45 × Midterm + 0.45 × Final + 0.10 × Attendance, rounded to an integer value.

The Final Letter Grade should be assigned as follows:

Course AvgFinal Grade
90–100A
80–89B
70–79C
60–69D
0–59F

Tasks

  1. Based on the requirements for the information product (report) above, define a list of data requirements for the StudentGrades.csv file.
  2. Based on these requirements and your assessment of the file, list the deficiencies you observe where the data does not meet the requirements. (You can use OpenRefine for this.)
  3. Explain your plan for remediating each deficiency.
