HW02 — Week 2 Assignment

Data Analysis

Explore the movie dataset with OpenRefine and write a report describing its structure, characteristics, and notable anomalies.

Original instructions: AsssessMovieDataset.docx

Instructions

Analyze the Dataset

  1. Install and open OpenRefine.
  2. Create a project and choose MovieDataset.csv.
  3. Click Next to load the file and start the project.
  4. Use the dropdown arrows beside each column header to open the Facet menu and analyze the column.
  5. Write a report detailing the characteristics of the data file, including overall statistics and any missing values, inconsistencies, problems, or anomalies you find.

Data Analysis Report

Describe what you observe in the file. Include the record count, field names and types, value distributions, blank values, unusual values, inconsistent labels, and other characteristics that deserve attention.

Finding an anomaly is not the same as proving a data quality error. Data quality can be determined only when the applicable data requirements are known.
