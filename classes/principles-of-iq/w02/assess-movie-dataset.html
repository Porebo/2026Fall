HW02

Data Quality Assessment

Original assignment instructions for analyzing MovieDataset.csv with OpenRefine.

Instructions

Complete the Assessment

Use OpenRefine for this assignment. You may optionally use AI to compare its results with those from OpenRefine.

  1. Download and install OpenRefine on your computer.
  2. Download MovieDataset.csv from this website.
  3. Open the OpenRefine application.
  4. Select Create Project.
  5. Click Choose Files and navigate to where you stored MovieDataset.csv.
  6. Click Next to load the file and start a new project. This should load 860 rows.
  7. Click the dropdown arrows beside each column header to open the Facet window and analyze the selected column.
  8. Write a report detailing the characteristics of the data, including overall statistics and any problems or anomalies, such as missing values or inconsistencies.

For information about facets and other OpenRefine features, see the OpenRefine documentation.
