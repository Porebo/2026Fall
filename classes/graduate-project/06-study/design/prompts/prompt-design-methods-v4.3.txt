PROMPT PARAGRAPH STRUCTURE

Prompt 01 has exactly one instruction paragraph: the shared presence-only
baseline and required output.

Prompt 02 repeats Prompt 01's baseline paragraph verbatim as paragraph 1, then
adds one persona/task/context/format paragraph as paragraph 2.

Prompt 03 repeats Prompt 01's baseline paragraph and Prompt 02's added paragraph
verbatim as paragraphs 1 and 2, then adds one explicit chain-of-thought
paragraph as paragraph 3.

The paragraph counts refer to the instructions after the divider in each prompt
file. File titles, version notes, and attachment lists appear before the divider
and are not part of the prompt text sent to the AI.
