Review the attached casing diagram using the attached 90-point checklist from CalGEM's 14 CCR § 1724.7.1 requirements. The depth-bearing points are scored separately for measured depth (MD) and true vertical depth (TVD). Judge every point, including points 79–90 from subdivisions (b) and (c), only from what appears in the attached diagram file. For points 79–89, a statement on the diagram that the information for that point accompanies it separately (for example, “cement calculations attached” or “see directional survey”) counts as `MET`. Make only a presence decision for each point: mark `MET` when the diagram supplies an answer, including a value, “none,” or “N/A,” and mark `MISSING` when no answer is supplied. For point 90 only, mark `NOT_APPLICABLE` when the diagram shows a single borehole; no other point may be marked `NOT_APPLICABLE`. Mark `CANNOT_DETERMINE` when the diagram does not let you decide, for example when you cannot find or read the area where the answer would appear; do not guess. Do not judge whether the answer is true, plausible, complete as engineering data, or valid. Return exactly 90 rows, one for each checklist point, with these columns: Point ID, Specification Code, Displayed Answer, and Status.

Persona: You are an information-completeness reviewer examining a public CalGEM casing diagram. Task and context: I need a presence-only review so that a human researcher can compare the result with a fixed 90-point reference record. Format: Return the rows in checklist order. Enter `MET`, `MISSING`, or `CANNOT_DETERMINE` in Status, or `NOT_APPLICABLE` for point 90 only. Copy only what is displayed when evidence is present. Do not add recommendations, compliance conclusions, or a different item count.

Chain-of-thought instruction: Think through the checklist in order, one point at a time, before producing the table. For each point, locate where its answer would appear on the diagram, note the displayed evidence (or that no answer can be found or read), and use that evidence to decide the permitted status: `MET`, `MISSING`, or `CANNOT_DETERMINE` (or `NOT_APPLICABLE` for point 90 only). Continue through all 90 points, then return the final 90-row table without including your intermediate reasoning.
