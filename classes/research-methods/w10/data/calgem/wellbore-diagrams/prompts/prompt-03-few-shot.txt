How the examples were built
---------------------------
The examples are derived from the wording of 14 CCR 1726.4.1, not from any
diagram. Each describes a made-up diagram with invented values and applies one
requirement's wording to it. No example uses a sampled diagram (W01-W30) or any
other real diagram, so the examples can neither reveal answers for the diagrams
under test nor favor one operator's drawing template.

Each example illustrates one way a requirement's wording decides the judgment:

  Example     Regulation wording                       What it illustrates
  (a)(1)(A)   "Operator, lease name, well number, and  a requirement listing
              API number of the well"                  several items is met only
                                                       when every item is shown
  (a)(1)(B)   "Date the well was spudded"               a single item shown is met
  (a)(1)(L)   "...including top and bottom of cement   showing part of a
              plug and the date(s) the plug(s) was      requirement (depths)
              emplaced, with method of determination"   without the rest (date,
                                                       method) is not met
  (a)(2)      "Measured depth and true vertical depth   "and" requires both; one
              shall be provided for all measurements"   depth reference alone is
                                                       not met
  (a)(5)      "For all wells to be used for gas         a requirement the
              injection and/or withdrawal..."          regulation limits to
                                                       certain wells does not
                                                       apply to other wells

The three judgments used, Meets, Does not meet, and Not applicable, follow from
the regulation's own structure: "shall at a minimum include all of the
following data" (met or not met) and paragraphs limited to certain wells
((a)(3) directionally drilled wells, (a)(5) gas injection and/or withdrawal
wells, (a)(6) wells with multiple boreholes), which are not applicable to other
wells.

The examples are written as a person would type them at a keyboard: short
sentences of the form "If a diagram shows ..., then (requirement) does not
meet," introduced with "Here's how I want each requirement judged. These are
made-up examples, not from the attached diagram." They are stated to be
made up so the AI does not confuse them with the attached diagram. The output
requested from the AI is still a table, as in level 2; only the examples are
in sentences.
